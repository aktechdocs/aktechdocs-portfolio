Enterprise Platform Release Notes

Production changelog, upgrade guidance, and resolved defects for NovaCore Platform.

Version 4.2.0

November 2026
Target Environment: Multi-Tenant SaaS & Hybrid Clusters • Build: build-prod-202611-0420 • Downtime: Zero-downtime rolling update

Breaking Mandatory API Token Expiration

Action Required: Static Personal Access Tokens (PATs) are rejected starting in this release. All programmatic clients must exchange credentials via /oauth/v2/token.
  • Enforced TTL: Requests lacking an active token TTL header receive an HTTP 401 Unauthorized response.

New Feature Granular RBAC Audit Logging

  • Audit Permission Scopes: Added isolated read scopes for compliance monitors: 
    scopes: ["audit:events:read", "audit:retention:read"]
  • External Log Pipeline: Automated streaming of signed, W3C-compliant JSON logs directly into customer AWS S3 and Azure Blob buckets.

Enhancement Database & Cache Performance

  • Partition Indexing: Reduced query latency on event collections exceeding 50M rows from 420ms down to 48ms.
  • Memory Footprint: Decreased Redis caching serialization load by 22% during peak sustained throughput.

Bug Fix Resolved Defects

  • NC-4412: Fixed an issue where outbound webhook retry counters aborted prematurely on HTTP 429 Too Many Requests.
  • NC-4428: Resolved a database race condition causing orphaned disk pointers during concurrent tenant purges.
  • NC-4450: Fixed SAML single logout (SLO) handlers failing to trigger immediate active token revocation.

Version 4.1.0

September 2026
Target Environment: Multi-Tenant SaaS • Build: build-prod-202609-0410

New Feature Geo-Distributed Routing

  • Regional Gateways: Added instant ingress routing across EU (Frankfurt) and APAC (Singapore) points of presence to adhere to local data residency standards.
  • Dynamic Rate Limiting: Configurable per-tenant throttling tiers adjustable via management API without restart.

Deprecation Legacy Authentication API

  • The legacy endpoint /api/v1/auth/login is deprecated and scheduled for decommissioning in release 5.0.0. Migrate integrations to /oauth/v2/token.

Platform Compatibility Matrix

  • Docker Engine: Version 24.0.0 or higher
  • Kubernetes: v1.28 through v1.31
  • PostgreSQL: v15.x, v16.x
  • Supported Browsers: Chromium ≥ 120, Firefox ≥ 120, Safari ≥ 17
