Enterprise Platform Release Notes

System changelog, upgrade steps, migration notices, and bug fixes for the NovaCore Multi-Tenant Cloud Platform.

Release 4.2.0 November 2026
Deployment Scope: Multi-Tenant SaaS & Standalone Private Clusters • Build Target: build-prod-202611-0420 • Downtime Required: None (Zero-downtime rolling update)

Breaking Changes API Token Expiration Requirements

Action Required: Permanent personal access tokens (PATs) are no longer accepted. All existing service tokens must be migrated to rotating OAuth2 service principals.
  • Mandatory Token TTL: API gateways now reject tokens without an explicit TTL header. All programmatic calls must rotate tokens using the /oauth/v2/token refresh workflow.

New Features Role-Based Governance & Audit Logging

  • Fine-Grained Role Access Control (RBAC): Added granular scopes for read-only audit exports: 
    scopes: ["audit:events:read", "audit:retention:read"]
  • Automated S3 Compliance Archive: Introduced an automated archival pipeline supporting direct streaming of raw W3C-standard JSON logs to customer-managed AWS S3 or Azure Blob storage buckets.

Enhancements Database Query Performance

  • Partition Indexing: Reduced query latency on tenant event tables exceeding 50 million records from 420ms to 48ms through partition pruning.
  • Memory Footprint: Reduced Redis cache serialization overhead by 22% during peak concurrent ingestion bursts.

Resolved Issues Critical Bug Fixes

  • NC-4412: Fixed an edge case where webhook events dropped delivery retry attempts when receiving an HTTP 429 Too Many Requests response from destination endpoints.
  • NC-4428: Resolved a race condition during concurrent workspace deletion that caused orphaned storage reference records in Postgres.
  • NC-4450: Addressed a UI synchronization glitch where active session counts failed to invalidate immediately after SAML single-logout execution.
Release 4.1.0 September 2026
Deployment Scope: Multi-Tenant SaaS • Build Target: build-prod-202609-0410

New Features

  • Multi-Region Ingestion Routers: Added automatic routing to EU (Frankfurt) and APAC (Singapore) gateway regions to comply with data residency mandates.
  • Dynamic Rate Limiting: Configurable per-tenant rate limit adjustments via admin management API without server restart.

Deprecation Notice

  • Legacy V1 Auth Endpoint: The /api/v1/auth/login route is deprecated and marked for removal in release 5.0.0. Use /oauth/v2/token.
