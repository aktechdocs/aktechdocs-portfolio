CustomerHub REST API v1 Reference

The CustomerHub API is organized around REST. All requests use standard HTTP verbs, return JSON-encoded responses, and implement standard HTTP response codes.

Base URL

https://api.customerhub.io/v1

Authentication

Authenticate API requests using Bearer tokens sent in the HTTP Authorization request header. All requests must be made over HTTPS. 

Authorization: Bearer sec_live_9a4f2c018e7d482

Status & Error Codes

Code Description
200 OK Request succeeded.
201 Created Resource created successfully.
400 Bad Request Missing or malformed payload attributes.
401 Unauthorized Missing, expired, or invalid API key.
404 Not Found The requested resource ID does not exist.

Endpoints

1. List All Customers

Retrieves a paginated list of registered enterprise customers.

GET /customers

Query Parameters

Parameter Type Default Description
limit integer 20 Number of records returned (max 100).
page integer 1 Page token for pagination offsets.

cURL Example

curl -X GET "https://api.customerhub.io/v1/customers?limit=2" \
  -H "Authorization: Bearer sec_live_9a4f2c018e7d482" \
  -H "Accept: application/json"

Response Example (200 OK)

{
  "status": "success",
  "data": [
    {
      "id": "cust_8921a",
      "name": "Acme Industrial Corp",
      "email": "ops@acmeindustrial.com",
      "tier": "enterprise",
      "created_at": "2026-03-15T08:22:11Z"
    }
  ],
  "meta": {
    "total_records": 1,
    "page": 1,
    "limit": 20
  }
}

2. Create a Customer

Creates a new organization record inside CustomerHub.

POST /customers

Request Body Schema

Field Type Required Description
name string Yes Legal or trading entity name.
email string Yes Primary technical contact email address.
tier string No Account tier: standard, professional, or enterprise. Default is standard.

cURL Example

curl -X POST "https://api.customerhub.io/v1/customers" \
  -H "Authorization: Bearer sec_live_9a4f2c018e7d482" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Global Logistics Ltd",
    "email": "integrations@globallogistics.com",
    "tier": "enterprise"
  }'

Response Example (201 Created)

{
  "status": "success",
  "data": {
    "id": "cust_9934f",
    "name": "Global Logistics Ltd",
    "email": "integrations@globallogistics.com",
    "tier": "enterprise",
    "created_at": "2026-11-11T09:30:00Z"
  }
}

3. Retrieve Customer by ID

Fetches full object attributes for a specific customer identifier.

GET /customers/{customer_id}

cURL Example

curl -X GET "https://api.customerhub.io/v1/customers/cust_9934f" \
  -H "Authorization: Bearer sec_live_9a4f2c018e7d482"

Response Example (200 OK)

{
